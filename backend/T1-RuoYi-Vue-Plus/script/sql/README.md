# SQL 脚本目录说明

本项目基于 RuoYi-Vue-Plus 5.6.0，数据库使用 **MySQL 8.0**。

## 目录结构

```
sql/
├── 01-框架基础/                 # RuoYi-Vue-Plus 框架核心表（MySQL）
│   ├── ry_vue_5.X.sql           # 系统核心表（用户、角色、菜单、部门等）
│   ├── ry_job.sql                # 定时任务表（XXL-JOB）
│   └── ry_workflow.sql           # 工作流引擎表（Flowable）
├── 02-项目业务基线-V1.0.1/       # 健身房业务初始基线
│   ├── 01_建表.sql               # 11 张业务表（门店/会员/教练/课程/排课/预约/签到/卡项/订单）
│   ├── 02_字典初始化.sql          # 业务字典数据（10 种字典类型）
│   ├── 03_菜单权限.sql            # PC 管理端菜单与按钮权限
│   ├── 04_OSS配置.sql             # MinIO 对象存储配置
│   └── 05_业务编号补齐.sql         # 业务编号字段补齐（ALTER）
├── 03-业务版本升级/              # 业务增量迭代
│   ├── V1.0.2_微信认证升级.sql     # 会员无感登录 + 教练微信激活
│   ├── V1.0.3_教练角色升级.sql      # 教练角色创建与 role_key 唯一约束
│   ├── V1.1.0_移动端索引优化.sql    # 移动端高频查询索引
│   ├── V1.1.1_活动管理.sql         # 活动运营表与卡项绑定
│   └── V1.1.2_预约重构.sql         # 预约类型区分（到店体验/卡项预约）
├── 99-框架升级归档/              # 框架版本升级（非全新部署需要）
│   └── update/                   # Ry 5.0 → 5.6.0 各版本增量
├── oracle/                       # Oracle 版框架 SQL（本项目不需要）
├── postgres/                     # PostgreSQL 版框架 SQL（本项目不需要）
└── sqlserver/                    # SQLServer 版框架 SQL（本项目不需要）
```

## 全新部署执行顺序

从零搭建数据库时，按以下顺序执行：

| 步骤 | 目录 | 脚本 | 说明 |
|------|------|------|------|
| 1 | 01-框架基础 | `ry_vue_5.X.sql` | 建立系统基础表 |
| 2 | 01-框架基础 | `ry_job.sql` | 建立定时任务表 |
| 3 | 01-框架基础 | `ry_workflow.sql` | 建立工作流表（如不使用可跳过） |
| 4 | 02-项目业务基线-V1.0.1 | `01_建表.sql` | 建立 11 张健身房业务表 |
| 5 | 02-项目业务基线-V1.0.1 | `02_字典初始化.sql` | 初始化字典数据 |
| 6 | 02-项目业务基线-V1.0.1 | `03_菜单权限.sql` | 初始化菜单与按钮权限 |
| 7 | 02-项目业务基线-V1.0.1 | `04_OSS配置.sql` | 配置 MinIO 连接信息 |
| 8 | 02-项目业务基线-V1.0.1 | `05_业务编号补齐.sql` | 补齐业务编号字段与唯一约束 |

## 升级执行顺序

在已有 V1.0.1 基线基础上升级时，按版本号顺序执行 `03-业务版本升级/`：

```
V1.0.2 → V1.0.3 → V1.1.0 → V1.1.1 → V1.1.2
```

## 特别注意

- 本项目使用 **MySQL 8.0**，`oracle/`、`postgres/`、`sqlserver/` 目录中的脚本仅用于跨数据库参考，**不要**在 MySQL 中执行。
- `99-框架升级归档/` 中的脚本仅在你需要从旧版 RuoYi-Vue-Plus 升级到 5.6.0 时有用。**全新部署直接从** `01-框架基础/` **开始**，无需执行这些升级脚本。
- `03_菜单权限.sql` 中的 menu_id 以 `2042601...` 开头的新编号体系为业务专用，与框架菜单不冲突。
- `04_OSS配置.sql` 中的 MinIO 地址需根据实际部署环境修改（当前为开发环境公网 IP）。
