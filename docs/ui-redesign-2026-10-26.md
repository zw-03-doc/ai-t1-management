# T1 小程序与 H5 页面改版

## 范围与视觉

重做 17 个会员、教练与公开页面，共用黑色背景、橙色主按钮、统一卡片与底部导航。保留原 T1 标志、门户照片及三张场馆照片；未使用业务证照照片，未引入外部素材。

- 入口：品牌与微信胶囊留出安全空间，保留一个主要训练入口；教练入口降低视觉权重。
- 会员：首页、约课、训练、我的四项导航。首页展示真实计划和预约；课程列表明确日期、教练、价格、余位与预约时间规则。
- 教练：工作台、课表、签到、学员、我的五项导航。重点展示今日课程、待签到与学员；代签到原因和储值扣款确认保留。
- 训练：今日安排、逐组记录、上次正式组参考、组间休息计时、计划编辑与进步统计。
- 公开训练指南：三分化、五分化模板，以及 24 个原创中文动作说明，支持肌群、器械和关键词查找。

## 文案处理

| 原表达 | 改版处理 |
| --- | --- |
| 畅练 · 约课 · 核销 | 入口改为训练导向的标题；核销只在教练实际操作场景出现 |
| 会员未登录 / 教练未登录 | 删除重复状态标签，主按钮随登录状态改变 |
| 多个同等权重的登录按钮 | 一个主要训练入口，一个浏览指南入口，教练入口置于页尾 |
| 手机号授权、激活流程等长段说明 | 从入口删除；在登录表单、绑定和激活操作中提供必要说明 |
| AppSecret、openid、SQL 等内部错误 | 对用户显示服务暂不可用，内部细节不进入提示 |
| 只有热身时的“0 kg 正式组” | 显示“暂无正式组”；真实自重正式组仍保留 0 kg |

保留与决策有关的课程价格、预约/取消/签到时间窗口、个人资料用途、浏览兴趣授权和操作确认。未添加虚构学员人数、评价、销量或训练成果。

## 内容与交互来源

参考 [DuarteSantos8/openGym](https://github.com/DuarteSantos8/openGym) 的动作库、历史重量、逐组训练和休息计时思路；本次代码与中文动作说明自行实现，未复制其代码、动作图片或视频。媒体仍由会员或教练上传，并沿用现有授权读取。

默认模板可先浏览，登录后打开对应草稿，不自动保存。未完成组不计入实际训练；热身与正式组分开，kg/lb 保留单位，图表按后端统一的 kg 展示。计时使用截止时间，切后台后恢复不累积误差。

## 验收边界

本次仅调整小程序/H5，不修改管理后台或后端数据结构。微信真实登录仍等待 `wx556bef49cde7a986` 对应的 AppSecret，未借用其他小程序身份。

微信模拟器中的训练样例仅用于本机视觉验收，所有请求被本地 mock 拦截，拒绝写入且不联网；不作为真实会员或生产业务数据。验收完成后恢复原接口与登录状态。

H5 与微信构建均通过。微信官方工具验收入口、指南、动作搜索、训练首页与逐组记录。逐组记录使用上述本机样例；禁用按钮采用明确暗底浅字，避免微信默认样式使文字不可辨认。
